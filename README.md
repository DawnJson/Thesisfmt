# 论文格式体检 thesisfmt

一个检查学位论文和期刊稿件格式的 Windows 小工具。把 `.docx` 拖进去，它会对照你学校或期刊的格式规范逐条检查，格式问题大多点一下就能改好，改不了的会告诉你在哪一段、应该是什么样。全程离线。

![论文格式体检主界面，左侧是问题清单，右侧是论文预览](docs/screenshot.png)

## 下载安装

到 [Releases](../../releases/latest) 下载 `.msi` 或 `-setup.exe`，装哪个都行，支持 Windows 10 和 11（x64）。安装包没有数字签名，SmartScreen 拦截时点「更多信息」→「仍要运行」。

## 能做什么

- 检查页面设置、页码、页眉、各级标题、正文、摘要与关键词、图表题注、三线表、脚注和参考文献编号，每条问题都写明应该是什么、实际是什么、出自规范哪一条。
- 一键修复格式，可以逐条修，也可以全部修，随时撤销。修复只改格式，不动文字。章序号、标点这类要改文字的问题，你逐条确认后才会写入。
- 电脑上装了 Word 或 WPS 时，借它排一遍版，再查表格跨页、续表表头、目录页码、章节另起页这些分页问题。
- 结果另存为修改后的副本，或者带 Word 批注的副本，原文件始终不动。

## 模板库

内置 115 个规则包，覆盖 83 所高校和 6 种期刊。其中 107 个逐条对照过单位的规范，标「已核对规范」；另外 8 个只有官方模板可依，标「未核对规范」。学校不在列表里的话，可以点「导入模板…」，从学校发的 Word 模板中提取规则。导入只是照搬模板的格式，模板本身有错，导入的规则也会跟着错。

## 隐私

论文只在你的电脑上处理。程序不联网，不做统计，不上传任何东西。

## 局限

- 这里的检查只是交稿前的自查，最终以学校的格式检测系统和老师的意见为准。
- 规范没写清楚的地方，程序不会替你猜，会列进「需人工确认」。
- 学校发了新规范而规则包还是旧版时，结果可能对不上，欢迎开 Issue 告诉我。
- 精确检查只在 Word 上实测过，WPS 还没在真机上验证。

## 参与贡献

规则查错了、规范更新了，或者想给自己学校加一个规则包，都欢迎开 Issue 或 PR。报告误报时请附上规则包名称、那条问题的内容和学校规范的链接。请不要提交从学校或期刊下载的模板和规范文件，它们的版权属于发布单位。

## 开发

需要 Node 20+、Rust 和 [Tauri 2 的系统依赖](https://v2.tauri.app/start/prerequisites/)。

```bash
npm install
npm run tauri dev      # 开发模式运行
npm run tauri build    # 构建安装包
cd src-tauri && cargo test
```

推送 `v*` 标签后，GitHub Actions 会自动构建安装包，并放进一个草稿 Release。
